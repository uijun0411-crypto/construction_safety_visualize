# 입력 통합 및 평가 비교 변경 (2026-10-13)

React 웹사이트와 FastAPI API에 적용했다. 기존 Streamlit 앱과 노트북은 변경하지 않았다.

## W 질문 검토

| 조건 | 기존 Q와 비교 | 처리 |
| --- | --- | --- |
| W001 | Q001은 주변 가연물 존재, Q002는 거리만 확인한다. 건물 구조 자체·내부·개구부 포함 여부까지 동일하게 확인할 수 없다. | 고유 질문을 위험 조건에 유지한다. 11m 경계나 위치를 거리 점수만으로 추정하지 않는다. |
| W002 | Q019의 하부 가연물 불티 착화 우려와 동일하다. 입력항목 DB 설명에도 작업반경 11m 이내 바닥 하부 및 더 멀리 떨어진 가연물 조건이 있다. | Q019 응답을 재사용한다. |
| W003 | Q020이 금속 구조물 반대면 가연물의 열전도·열복사 착화 우려를 확인한다. | Q020 응답을 재사용한다. |
| W004 | Q004는 배치 상태이며 예외 적용 의사와 다르다. | 예외 적용 질문을 위험 조건에 유지한다. |

서버에서 있음→예, 없음→아니오, 확인불가→확인불가로 변환한다.
기존 클라이언트가 W002/W003 값을 보내도 현재 Q019/Q020 응답을 우선한다.
기록에는 기존 형식의 네 W 응답을 모두 보존한다. 기존 판정 규칙과 점수 산식은 유지한다.

## 비교 표시

- 위험지수·증감, 잠정 위험등급, 변경 항목 수를 요약한다.
- 항목별 이전/이후 응답과 가중점수 막대, 위험 증가/감소를 표시한다.
- 조건제외·시점제외는 ‘평가 제외’로 표시하고 막대·증감·최대 변화 순위에서 제외한다.
- 실제 적용 항목의 0점은 0.0으로 표시한다. 자료 누락·미산정도 0으로 변환하지 않는다.
- 재사용된 W 변경은 대응 Q 변경과 중복 집계하지 않는다. 고유 W 변경은 별도 표시한다.
- 가장 큰 변화는 비교 가능한 항목의 절대 변화량으로 선택하며 동률을 모두 표시한다.
- 데이터·엔진·평가시점·분모가 다를 때 점수 비교를 제한하는 기존 정책을 유지한다.
- 비교 API에서도 제외 항목의 가중점수는 null로 반환한다. 저장 원본은 수정하지 않는다.
